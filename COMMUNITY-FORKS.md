# Community forks and improvements

This page is a directory of independently maintained versions and useful enhancements of **PortGuard Mini**. The original author does not have to personally receive or merge every change.

## Add your project

Fork this repository, publish your work, then open a pull request adding a row here. Include a working link and a concise description. You can also submit a link to an unrelated repository or patch set, as long as it clearly identifies how it relates to PortGuard Mini. Links are reviewed for relevance and safety.
