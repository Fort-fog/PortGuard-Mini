# PortGuard Mini v0.8.4 — точечное исправление Nginx

v0.8.4 продолжает v0.8.3 без изменения архитектуры и функциональности PortGuard Mini.

Исправлена только проверка стандартного подключения `/etc/nginx/conf.d/*.conf` в `/etc/nginx/nginx.conf`:

- активный `include` теперь распознаётся при нескольких пробелах и табуляции;
- допускаются пробелы перед `;` и комментарий после директивы;
- полностью закомментированная строка `# include ...` больше не считается активным подключением;
- строка, где нужный текст встречается только внутри комментария, также не считается активной.

Новые зависимости не добавлены. Nginx-конфигурация по-прежнему не переписывается: PortGuard только использует собственный `/etc/nginx/conf.d/zz-portguard-mini.conf`, если стандартный `conf.d` действительно подключён.

Остальное поведение v0.8.3 сохранено без изменений: SSH, Apache, PHP, baseline, watcher, периодический read-only audit, emergency-команды, install/rollback и существующие systemd units.
